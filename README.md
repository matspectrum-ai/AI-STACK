# AI-STACK

AI-STACK is an open-source AI-native engineering harness built around an explicit Engineering Graph.

The project is currently in **Phase 0 — Repository Foundation**. Architecture is intentionally specification-first: no runtime implementation is accepted before contracts and fail-first tests exist.

## Direction

- **Execution kernel:** OMP / OhMyPI
- **Control plane:** AI-STACK Engineering Graph
- **Development disciplines:** Document-Driven, Spec-Driven, Contract-Driven, Test-Driven, Context-Driven, and Eval-Driven Development
- **Architecture principle:** Graph Engineering
- **External frameworks:** treated as sources of primitives, never as competing control planes

## Candidate primitive sources

The current research set includes gstack, Superpowers, BMAD Method, OpenSpec, GitHub Spec Kit, Ralph, and selected concepts from archived GSD work. Inclusion is provisional until `STACK-RFC-001` is accepted.

## Project status

The repository is being initialized. The first deliverables are the project constitution, capability matrix, architecture RFC, graph contracts, and fail-first acceptance tests.

See `docs/` as the project evolves.
